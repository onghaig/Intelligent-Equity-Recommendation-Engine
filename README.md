# Intelligent-Equity-Recommendation-Engine
Author: Gavin Onghai

Overview This program is a stock investment recommendation engine. It utilizes a ridge regression machine learning pipeline with a highly interpretable heuristics scorecard that turns stock history into an actionable thesis.

The program is a dynamic algorithm capable of rating an extremely diverse 85-stock universe, producing analyst-like qualitative memos structured to explain the conviction proficiently, elaborate on missing data transparently, and pivot gracefully based on the client's desires (e.g. Income vs. ESG vs. Growth).
How to Run:
Step 1: Create VENV

    python3 -m venv ps2_env
    source ps2_env/bin/activate

Step 2: Install dependencies

    pip install yfinance yahooquery scikit-learn pandas numpy

Step 3: Run the help command to see what you can do!

    python hw2.py --h
